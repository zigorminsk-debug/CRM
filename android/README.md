# Приложение инженера для Android (CRM-Engineer)

Инженер получает на телефон заявки по своим зонам, строит маршрут на день и отмечает
чекбоксами готовность: **на месте** либо **забор в офис**.

## Что умеет

1. **Вход**: адрес сервера (`http://<публичный IP или домен>:8000`), логин и пароль инженера.
2. **Маршрут на день** — заявки отсортированы по срочности (аварийные/срочные — первыми)
   и по географии (ближайший сосед), с расчётным временем прибытия и пробегом.
3. **Кнопка «Поехали»** — заявка переводится в статус «В работе», открывается **Яндекс.Навигатор**
   по координатам адреса (deep-link `yandexnavi://build_route_on_map`). Если навигатор не установлен —
   открываются Яндекс.Карты с маршрутом.
4. **Чекбоксы готовности**:
   * «Готово на месте (выполнено)» — статус *Выполнено на месте*;
   * «Забор в офис (картридж/оборудование)» — сервер **сразу ставит доставку заказчику на следующий
     рабочий день**; в разделе «Доставка заказчикам» дату можно **перенести**, если оборудование не готово.
5. **Перенос заявки** на другую дату с указанием причины.
6. **Уведомления** о новых заявках, переносах и о передаче зоны на время отпуска
   (фоновый сервис опрашивает `/api/engineer/feed`).
7. **Весь маршрут в Яндекс.Картах** одной ссылкой (все точки дня).

## Сборка APK

Требуется Android Studio (или Android SDK + JDK 17).

```bash
# в Android Studio: File → Open → папка android/ , затем Build → Build Bundle(s)/APK(s) → Build APK(s)
# либо из командной строки:
cd android
./gradlew assembleDebug          # первый запуск создаст wrapper автоматически в Android Studio
# результат: app/build/outputs/apk/debug/app-debug.apk
```

Для подписанного релиза:

```bash
./gradlew assembleRelease      # нужен keystore, настройте signingConfigs в app/build.gradle
```

Готовый файл можно положить на сервер в папку `downloads/` под именем **CRM-Engineer.apk** —
он сразу появится на странице `http://<сервер>:8000/downloads`.

## Быстрая альтернатива без сборки APK

Сервер отдаёт тот же функционал как **PWA**: `http://<сервер>:8000/m`.
Страницу можно «установить» на телефон (Chrome → «Добавить на главный экран») — приложение
открывается как обычное, работает с тем же API, уведомлениями и кнопкой Яндекс.Навигатора.

## Структура

```
app/src/main/java/by/crm/engineer/
  Api.kt            — вызовы REST API сервера (логин, маршрут, «Поехали», чекбоксы, доставки, лента событий)
  Task.kt           — модели заявки и доставки
  MainActivity.kt   — вход, маршрут на день, действия инженера
  TaskAdapter.kt    — списки заявок и доставок
  FeedService.kt    — фоновая лента заявок и push-уведомления
```
