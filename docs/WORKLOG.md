## Ключевые решения и почему так

1. **Сбор адресов — из OpenStreetMap (ODbL), в GitHub Actions.** Из песочницы
   разработки Overpass/Nominatim недоступны (curl 000), из CI — работают.
2. **Данные коммитятся в репозиторий** (`server/app/data/`), а не в артефакты:
   артефакты CI из песочницы скачать не удалось (blob-хранилище блокируется),
   а git-объекты ходят всегда.
3. **Дома — отдельно от улиц** (`minsk_houses.csv.gz`, таблица `house_index`),
   поиск «улица, дом N» даёт точку конкретного дома (precision `exact`).
4. **Справочник приходит на белорусском** (OSM), пользователи пишут по-русски:
   ключи улиц нормализуются в обе стороны (і→и, ў→у, -скага→-ского, варианты
   первых гласных: Дзержинского↔Дзяржынскага, Притыцкого↔Прытыцкага).
5. **Районы города — admin_level=9** (не 7!). Минск = relation 59195 (уровень 4!),
   Минский район = 59190 (уровень 6). Это главная причина прежней
   «неправильной принадлежности».
6. **Зона заявки**: район из адреса → (если регион назван явно — он) → ближайший
   центр зоны → текст адреса (`server/app/zones.py: resolve_zone`).
7. **Логи сборщика при провале коммитятся в `.ci/last-harvest.log`** — их иначе
   не достать (API логов CI недоступен из песочницы, артефакты тоже).

## Известные ловушки инфраструктуры

- **Токен GitHub флапает** (401 Bad credentials часами) — лечится
  переподключением GitHub в Arena; CI в это время работает сам.
- **Локальный HEAD песочницы иногда откатывается** к старому коммиту при простое.
  Перед коммитом: `git fetch origin '+refs/heads/*:refs/remotes/origin/*'`,
  сверить с `git log origin/arena/01a0e2c9-crm`, спасать несмердженные файлы
  в /tmp, `git reset --hard origin/...`, вернуть файлы, коммит, пуш.
- **/tmp чистится между ходами** — venv и временные скрипты пересоздавать:
  `python3 -m venv /tmp/crmvenv && /tmp/crmvenv/bin/pip install fastapi uvicorn pydantic python-multipart`.
- **Overpass**: кириллические диапазоны в regex → HTTP 400; объединение+рекурсия
  `(._;>;)` на крупных отношениях → 400; перегрузка → 200 с пустым `elements` и
  `remark` (считать ошибкой!); 429/504 → ретраи. Подробности и рецепты:
  `docs/ADDRESS-INDEX.md`.
- **workflow_dispatch доступен только из default-ветки** — на рабочей ветке сбор
  запускается push'ем в `tools/build_street_index.py` (триггер `paths`).

## Чеклист «принадлежность районов корректна»

```bash
grep -E "^(Фабрициуса|проспект Дзержинского|Кальварийская);" server/app/data/minsk_streets.csv
# ожидание: Фабрициуса → Первомайский; пр. Дзержинского → Московский; Кальварийская → Центральный
grep -i "^Колодищи" server/app/data/minsk_streets.csv      # → Минский район, microdistrict
zcat server/app/data/minsk_houses.csv.gz | grep -i "дзяржынскага;123;"  # дом есть
head -8 .ci/harvest-report.txt                             # полигоны: 8 районов
```
